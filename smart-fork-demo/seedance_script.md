## 1. 最关键：机位的物理设定（务必放在提示词最前面）

AI 最容易犯的错，是把画面理解成"有人拿着叉子吃饭的第三人称镜头"，或者"跟拍叉子"的镜头。都不对。这是**装在叉子上的摄像头**拍的。

### 1.1 摄像头装在哪里

```
侧视示意（→ 为叉子指向）

        镜头 ◉―――――――――――→  视线（比叉身向下约 25°）
         │ ↑ 约 2cm
 手握 ═══╧══════叉颈═══ 叉面 ═══╤╤╤╤  四根叉齿
  (在镜头后方,画面外)    │← 约 3cm →│← 约 4cm →│
```

- 一颗微型广角摄像头**刚性固定在叉颈上**。它在叉齿根部后方约 3cm、叉面上方约 2cm，镜头沿叉身朝前，向下俯约 25°，正对叉齿区。
- 摄像头和叉子是一体的。**叉子在画面里的位置、大小、角度永远不变**，像焊死在屏幕上。
- 手握在摄像头**后方**的叉柄上，所以**画面中永远看不到手、手指、叉柄，也看不到吃饭的人的全身**。

### 1.2 叉子在画面中的固定构图（每一帧都必须相同）

- 白色（瓷白色、带光泽的塑料或陶瓷）**四齿叉头**从**画面底边正中**伸进来。底边处的叉面宽约占画面宽度的 50%，左右两侧被底边切掉。
- **四根叉齿**向上伸，因透视向中间略微汇聚，**齿尖大约在画面从上往下 30% 的高度**。
- 叉面和叉齿占据画面下方约 2/3 的中间区域。叉齿之间的缝隙能看到后面的景物。
- 叉齿根部是圆弧形的齿缝。叉面边缘圆润，有柔和高光，会反射一点周围的颜色。
- **全片叉子始终是四根齿**，形状不变，不会弯曲、融化、增减齿。

### 1.3 运动规则：动的是世界，不是叉子

- 手移动叉子时，**整个背景**（碗、桌面、房间、脸）在画面里平移、旋转、放大缩小，**叉子纹丝不动**。
- 手腕转动时，背景里的地平线和桌沿会**倾斜旋转**，叉子依然端正竖直。
- 快速抬起和转向时，**背景有明显运动模糊**。叉子和叉上的食物**不模糊**，因为它们相对镜头是静止的。
- 叉上的食物和叉子一起刚性固定在叉齿中部，只允许极轻微的颤动。
- 有轻微的手持抖动：背景细微晃动，频率约 1–5Hz。叉齿扎进食物的瞬间，整个画面有 1–2 帧小幅震动。

### 1.4 镜头与对焦

- 超广角，约 75° 水平视角，有轻微桶形畸变（画面四角的直线外凸），四角轻微暗角。
- **固定对焦约 5–6cm**：
  - 叉子和叉上的食物：最清晰；
  - 碗里距离 3–10cm 的食物：基本清晰、略软；
  - 远处的房间：柔和虚化；
  - **嘴唇和脸贴近到 1–4cm 时：严重失焦**，变成柔和的肉色、粉色色块，看不清细节。这是真实感的关键，**不要把嘴唇拍得清晰锐利**。

### 1.5 画质（廉价微型摄像头的质感）

偏冷偏紫的白平衡，暗部发灰带紫；画面略软但有轻微数字锐化；暗处噪点明显，ISO 噪点带彩色斑块。**自动曝光有滞后**：从明亮的碗转向较暗的脸时，画面先变暗，约 0.3 秒后被提亮，噪点同时增加。白色叉子在亮处容易轻微过曝。整体像智能餐具、内窥镜或运动相机的实拍素材，**不是**电影感、美食广告或 CG。

## 2. 场景、道具与连续性

- **碗**：同 @Image1。白色浅圆碗，深灰色碗沿，放在浅米色桌面上。从吃饭的人这一侧看过去：**牛排片斜排在左下（离人最近）**，芝麻菜和菠菜在左上，**溏心煎蛋在正中偏右**，烤小番茄和番茄酱汁在右下，谷物和黑豆在右上。
- **光线**：室内傍晚，暖色顶灯从上方照下，旁边有一扇偏冷光的窗户。叉子靠近碗时，叉子的**柔和阴影**会落在食物上。
- **吃饭的人**：普通成年人，只以**下半张脸极近特写**出现（鼻底、上下唇、下巴）。自然唇色，不涂口红，皮肤有真实纹理，可能有少量胡茬。身后是虚化的房间和深色上衣。
- **食物物理**：
  - 牛排片：粉红色的切面，边缘焦褐，约 0.7cm 厚。被叉穿时有一点阻力，肉片略微下压后回弹。
  - 芝麻菜和菠菜：叶片层叠，被叉起时叶缘下垂、轻微抖动，可能掉下一小片碎叶。
  - 烤小番茄：表皮微皱，被叉破时渗出少量汁水。
- **碗内连续性（必须保持）**：每吃掉一口，碗里对应的位置就**少一块**，露出下面的食物（下一片牛排、底层的菜叶、番茄酱汁）。被吃掉的食物不能再出现在碗里。煎蛋全程不动。

## 3. 逐帧分镜（24fps，F0–F731）

### 3.1 每一口的 12 个动作阶段（模板）

每一口时长 7.2 秒，共 173 帧，都由下面 A–L 十二个阶段组成。"相对时间"指从这一口开始算起的秒数。

| 阶段 | 相对时间 | 叉子与机位 | 画面里看到什么 | 对焦、曝光、质感 |
|---|---|---|---|---|
| **A 接近** | 0.00–1.15s | 叉子从碗上方约 6–7cm 处，叉尖朝下、前倾约 40°，缓缓移向目标食物。 | 目标食物从远处变大，移到**叉齿尖正上方偏中**的位置。碗沿和桌面在画面上半部和四周缓慢滑动。 | 碗中食物清晰，曝光稳定。 |
| **B 下压** | 1.15–1.70s | 下降到距食物约 2cm，再降到贴近表面，前倾加大到约 50°。 | 目标食物占满画面上方 2/3，纹理放大，叉子的柔和阴影压到食物上。 | 食物离镜头约 4cm，略软。 |
| **C 刺入** | 1.70–1.95s | 叉齿刺入食物约 0.3–0.5cm。 | **叉齿尖消失在食物里**，看起来是插进去，不是悬在上面。整个画面有 1–2 帧小幅震动。 | 无运动模糊。 |
| **D 稳住** | 1.95–2.30s | 停顿，轻微左右晃动，确认叉牢。 | 食物已经穿在叉齿中部。 | — |
| **E 提起** | 2.30–2.85s | 竖直抬离碗面约 4cm，前倾减小到约 30°。 | 食物**立在叉齿上，横跨叉齿**，留在画面中部。碗面在下方后退变小，**原位置出现一个缺口**，露出下面的食物。叉子阴影从碗里移开。 | 背景开始轻微运动模糊。 |

| **G 送到嘴前** | 3.55–4.25s | 叉子水平前推，叉尖对准嘴，从距脸约 10cm 推近到约 5cm。 | 吃饭的人的**下半张脸铺满背景**：鼻底在画面上沿，**嘴正好在叉齿尖正前方（画面上部中央）**，下巴在叉面后面。**嘴唇自然张开约 2cm**，能隐约看到暗色口腔和一点上门牙。 | 脸部失焦、柔和。叉子进入脸的阴影，**整体变暗**，自动曝光随后慢慢提亮，噪点增加。 |
| **H 入口** | 4.25–4.70s | 叉子再前推约 5cm，叉齿和食物整体送进口中，镜头离嘴唇只剩约 3cm。 | 食物从上下唇之间滑进去后消失。**画面上半部被暗红、近黑的口腔占据**，四周是极度虚化的粉色嘴唇和肉色脸颊。白色叉面仍在画面下部，被阴影压暗。叉齿进入口腔的部分几乎全黑，只带一点红色。 | 最暗的时刻：严重失焦，噪点最明显，偏暖红。 |
| **I 闭唇** | 4.70–5.25s | 叉子停住。嘴唇在叉齿上下合拢，把食物留在嘴里。 | 上下唇压在叉齿上，嘴缝收成一条只容叉齿穿过的细缝。**食物在嘴里被唇齿刮下**（约在本阶段 0.45s 处），从这时起叉子上已经没有食物。 | 依旧很暗、很虚。 |
| **J 抽出** | 5.25–5.85s | 叉子向后抽出约 6cm。 | 嘴唇贴着叉齿滑过，**干净、空着的四根叉齿**从唇缝里露出来，表面略有湿润反光。嘴唇随后闭合，下巴开始轻微咀嚼。脸部后退，稍微变清楚。 | 曝光回升，噪点减少。 |
| **K 回落** | 5.85–6.60s | 手腕下压，同时反向转约 70°，叉子回到碗上方约 13cm 高处，再次前倾。 | 脸从画面上方或一侧移出，房间亮斑扫过，碗从画面底部滑回来。 | 背景运动模糊，曝光短暂过亮后回落。 |
| **L 悬停** | 6.60–7.20s | 在碗上方约 6–10cm 处稳住，叉尖朝下、前倾约 40°。 | 透过叉齿间隙和四周，能看到大半个碗（已经少了刚吃掉的那块），下一口的目标进入画面。 | 碗中食物清晰，曝光稳定。 |

## 6. 常见跑偏与修正

| 现象 | 修正：在提示词里加强这句 |
|---|---|
| 生成成第三人称镜头，有手拿着叉子 | "摄像头装在叉子上，画面中永远看不到手、手指和叉柄" |
| 叉子在画面里移动、旋转、忽大忽小 | "叉子在每一帧中的位置、大小、角度完全不变，像焊在屏幕上，只有背景在动" |
| 叉齿数量变化或变形 | "始终是同一把白色四齿叉，四根齿形状不变" |
| 食物飘在叉子上方，没有插进去 | "叉齿刺入食物，叉尖没入食物中，食物横穿在叉齿中部" |
| 嘴部恐怖、牙齿特写、口红 | "嘴唇贴近时严重失焦成柔和肉色，自然唇色，不要清晰锐利" |
| 画面太干净、像广告片 | "廉价微型摄像头，偏冷偏紫，彩色噪点，自动曝光滞后，非电影感" |
| 被吃掉的食物又回到碗里 | "每吃一口碗里对应位置少一块，露出下面的食物，被吃掉的不再出现" |
| 抬起和转向时叉子也模糊了 | "运动模糊只出现在背景，叉子和叉上食物始终清晰" |
