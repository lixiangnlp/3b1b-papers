# 智能叉子逐口进食演示视频

`fork_steak_salad.mp4`：30 秒、960×544、24fps。模拟叉柄上的摄像头朝向叉齿拍摄，逐口吃牛排沙拉
（牛排 → 芝麻菜 → 小番茄 → 牛排，共 4 口），画面风格参照智能勺子吃玉米粒的实拍视频。

这是用 `steak_salad.png` 作为碗内纹理、在 numpy 中做 2.5D 光线投射合成的结果，不是实拍，也不是生成式视频模型的输出：

- 叉子是白色光泽塑料材质的 3D 几何体，摄像头刚性固定在叉颈上；
- 碗/桌面、嘴部、躯干和房间分别是平面或环境贴图，带景深、运动模糊和叉子投影；
- 叉起的食物是从照片中抠出的高度场卡片，叉起瞬间与碗内纹理无缝替换，原位置用相邻纹理（下面一片牛排、叶子等）填补；
- 后期加了滞后的自动曝光、偏冷紫的白平衡、传感器噪点、暗角和锐化，模仿廉价摄像头。
