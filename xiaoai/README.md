# 小爱同学 · 九年（2017 → 2026）

一支约 89 秒的动画短片，讲小爱同学从 2017 年一台 AI 音箱里的声音，一路走到 2026 年能跨应用办事的超级小爱。片子用代码逐帧生成：画面是一个 HTML 页面加一个确定性的 `render(t)` 函数，配乐和音效用 numpy 现场合成，没有用任何采样素材。

> 这是非官方的致敬短片。logo 归小米所有；片中出现的日期、数字都来自公开报道和小米集团业绩公告，出处列在本文末尾。对话、闹钟、车控、识别、订餐这几处界面只是示意，不对应真实截图。

| 规格 | |
|---|---|
| 成片 | `release/xiaoai_2017-2026.mp4`（已提交到仓库；重新构建的产物在 `build/`）：1920×1080、60 fps、H.264 High + AAC 256k，响度 −14 LUFS |
| 浏览器版 | `index.html`：可以拖进度条、按空格播放，配乐同步（需要先运行一次构建，生成 `build/music.m4a`） |
| 字体 | MiSans（小米官方字体，用的是 npm 上的 `misans` 子集包） |
| 配乐 | 原创。112.5 BPM，每章 3 小节，换章都落在强拍上 |

开场“小爱同学”的四个音节在配乐里是一个四音动机（A–D–F♯–A），“我在”是落回主音的两音应答（F♯–D）。结尾问答时，这个动机会再完整出现一次。

## 构建

```bash
cd xiaoai
npm install                      # MiSans 字体
pip install numpy scipy          # 配乐合成
python3 build.py                 # 卡点 → 配乐 → 逐帧渲染(60fps, 3 进程) → 合成 → 验收
```

Playwright 和 Chromium 需要预先装好（`require('playwright')` 能用就行；新机器上可以运行 `npm i -D playwright && npx playwright install chromium`）。常用的单步命令：

```bash
node render.js stills 2.7,13.5,44   # 抽静帧到 build/stills/，再用 python3 contact.py 拼成触表
python3 build.py audio              # 改了动画时间后，重新生成音效卡点和配乐
python3 build.py --fps 30           # 快速预览
```

### 目录

```
index.html      舞台 + 字体 + 脚本
css/film.css    版式（1920×1080 固定舞台）
js/core.js      缓动、阻尼弹簧、逐字入场、年份里程表
js/logo.js      logo 几何重建（四个色层 + 笔刷蒙版 + 粒子采样）
js/scenes.js    时间表、文案、每一章的视觉、背景与 HUD
js/player.js    浏览器播放器（渲染模式下不启用）
render.js       Playwright 逐帧截图 → ffmpeg；另有 stills / cues 模式
music.py        配乐与音效合成（读 build/cues.json 卡点）
build.py        一键构建
```

### 关于 logo

logo 没有直接贴图，而是从原图重建成矢量：
- 顶部是一个正圆（r≈50.2）；
- 两条外边是它分别与左下、右下圆的外公切线；
- 右下是一个正圆（r≈64.5）；
- 缺口和左下圆头用最小二乘拟合成三次贝塞尔；
- 四块渐变的端点和色标从原图像素回归得到。

与原图逐像素比较，平均误差约 1/255。四个色层各自带一条“笔刷中线”蒙版，开场一笔画出 logo 的动画就是靠它做的。
